# Projects

One project per file. The key fields are **status**, **where you paused**, and
**next step** — so you can resume cold without re-deriving context.

Template (`projects/<project>.md`):
```
# <Project>
> One-line goal.
Status: active | paused | done | shelved
Updated: YYYY-MM-DD

## Goal
What done looks like.

## Where I paused
The last thing I did / the current state.

## Next step
The single next concrete action.

## Log
- YYYY-MM-DD — progress note.
```
